# Taste of Japan — 公開と Google AdSense 収益化の手順

最安ルート：**ホスティング無料 ＋ ドメイン無料 ＋ AdSense 無料**。初期費用 ¥0 です。

| 項目 | 費用 |

| ホスティング（GitHub Pages） | ¥0 |
| ドメイン（無料サブドメイン `xxx.github.io`） | ¥0 |
| ドメイン（独自 `.com`） | 約¥1,200/年（任意） |
| Google AdSense | 無料（収益はクリック報酬） |
| **合計（最安）** | **¥0** |

## ステップ0：審査に通す下準備（最重要）

AdSense は「実在・正確で独自性のあるコンテンツ」を要求します。現在の `js/data.js` は**サンプルデータ（架空の住所）**なので、このまま審査に出すと却下されやすいです。

- [ ] `js/data.js` を実在のレストラン情報に差し替える（名前・住所・営業時間・価格を正確に）
- [ ] `about.html` / `privacy.html` の連絡先メールを自分のものに変える
- [ ] `privacy.html` の最終更新日を直す
- [ ] できれば記事を増やす（エリア別ガイド、インタビュー、季節特集など。15〜20ページ以上推奨）

## ステップ1：GitHub で公開（無料・所要30分）

### 1-1. GitHub アカウントを作る（初めてのみ）

1. ブラウザで <https://github.com> を開く
2. 右上の **「Sign up」** をクリック
3. メールアドレス → **「Continue」**
4. パスワードを決めて入力 → **「Create account」**
5. 届いたメールの認証コードを入力（またはメール内のリンクを押す）
6. 無料プラン（Free）を選んで質問をスキップ

### 1-2. リポジトリを作る（サイトを入れる箱）

1. ログイン後、画面**右上の「＋」アイコン**をクリック
2. **「New repository」** をクリック
3. 設定を埋める：
   - **Repository name**：`taste-of-japan`（半角英数字・スペースなし）
   - **Description**：空欄でOK
   - **Public** を選択（Private だと有料プランが必要）
   - **「Add a README file」にはチェックを入れない**
4. 緑の **「Create repository」** ボタンを押す

### 1-3. ファイルをアップロードする

1. リポジトリのページで、緑の **「Add file」** ボタン → **「Upload files」**
2. 画面中央の破線の枠に、**このサイトのフォルダごと**ドラッグ＆ドロップ
   - 入れるもの：`index.html` `about.html` `privacy.html` `ads.txt` `serve.ps1` `README.md`、`css/` フォルダ、`js/` フォルダ、`.github/` フォルダ
   - フォルダをドロップできない場合は、フォルダの中身をすべて選択（Ctrl+A）して一度にドロップ
3. アップロードが終わるまで待つ（進行バーがなくなるまで）
4. 下にスクロールし、**「Commit changes」** の欄にメッセージを入力（例：`first upload`）
5. 緑の **「Commit changes」** ボタンを押す

### 1-4. GitHub Pages を有効にする

1. リポジトリ画面の**上段メニュー**で **「Settings」** タブをクリック
2. 左側メニューの **「Code and automation」** の中の **「Pages」** をクリック
3. **「Source」** で **「Deploy from a branch」** を選択
4. **Branch**：`main`、**Folder**：`/ (root)` を選択
5. **「Save」** を押す
6. **1〜2分待って**から Settings → Pages を再読み込み
   - **「Your site is live at」** というリンクが出たら完成

### 1-5. サイトを開く

`https://<あなたのユーザー名>.github.io/taste-of-japan/`

例：ユーザー名が `satoshi` なら → `https://satoshi.github.io/taste-of-japan/`

> `.github/workflows/deploy.yml` を使いたい場合は、Source を「GitHub Actions」に設定。push するたび自動デプロイされます。

### つまずきやすいポイント

| 症状 | 対処 |
|---|---|
| 最初の1分は404になる | 1〜2分待って更新。Pagesは遅延します |
| 文字だけ出てデザインが崩れる | `css/` `js/` フォルダごとアップロードできているか確認 |
| フォルダをドロップできない | フォルダの中身を全部選択して一度にドロップ |
| 「Add a README file」にチェックを付けた | 問題ありません。そのまま手順1-3へ |

### 修正・更新したいとき

同じ手順1-3（Add file → Upload files）で同じファイルを上书き → Commit するだけ。1〜2分で反映されます。

## ステップ2：独自ドメイン（任意・年間約¥1,200〜）

1. ムームードメイン・お名前.com などで `.com` を取得
2. リポジトリ直下に `CNAME` ファイルを作り、ドメイン名だけ記入（例: `taste-of-japan.com`）
3. GitHub の Settings → Pages → Custom domain にドメインを入力
4. 表示される A レコード / CNAME をドメインの DNS に設定

---

## ステップ3：Google AdSense に申請

1. [adsense.com](https://adsense.com) にログイン（Google アカウント、**18歳以上**）
2. 「サイトを追加」で公開 URL を登録
3. 審査を待つ（通常 **数日〜2週間**）。審査中はサイトを公開したまま何も操作不要
4. 承認されたら
   - ダッシュボード → 広告ツール → 広告コードを取得
   - `index.html` の `<head>` 内の `★ AdSense` コメントを外してスクリプトを貼る
   - **Auto ads** を有効にすれば、広告枠の編集は不要です
5. ダッシュボードの ads.txt の内容を、ルートの `ads.txt` に貼る

---

## ステップ4：収益を受け取る

- 報酬 = クリック単価 × クリック数。初月は数十円〜数百円が現実的
- **$100** に達すると支払い可能（日本は銀行振込。本人確認・住所確認が必要）
- 広告収入は **確定申告** の対象

## 禁止事項（違反すると即失格）

- 自分で広告をクリックしない
- 広告を誘導するような配置にしない
- 架空の情報を載せない

## AdSense が通らなかったらの代替

- **アフィリエイト**: 食べログ・一休.com・Booking.com などの提携（飲食店紹介サイトに相性◎）
- 別の広告ネットワーク（Google Ad Manager など＝上級者向け）
